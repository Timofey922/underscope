Plugging Underscope into a listing flow

Underscope is four small APIs and a page that takes a VIN in the URL. Nothing here needs access to ACV's systems today. These are the connection points a partner would use, and they all work now.

Where it sits

ScanVIPER condition report, photos, scan-tool codes
UnderscopeVerified title, repair estimate, fix vs. sell-as-is with two net ranges
Seller decidesFix and relist, or list as-is, with the evidence attached
LaneDealer wholesale for fixed cars, salvage for as-is

In a pilot it would run silently next to today's lane rules (shadow mode), and only change routing on a small randomized slice, so the lift can be measured before anyone relies on it.

1. Link to it from any listing

Any page that knows a VIN can open a prefilled check. Add run=1 to run it straight away.

https://underscope-eight.vercel.app/?vin=1FTEW1EP6JKD12345&codes=P0299,P0171&title=clean&run=1

Optional: title (clean, salvage, rebuilt, flood, non_repairable, lemon), codes, clean (wholesale value), comps (comma-separated sold prices). Registered vehicles fill in their verified title and values on their own. Every result has a Copy link button that produces one of these.

Open a sample check

2. Bookmarklet: one click from a listing page

Drag this button to your bookmarks bar. On any page showing a vehicle (a dealer listing, an auction lot, a condition report), click it. It finds the VIN on the page, confirms it with the VIN check digit, and opens Underscope with that vehicle.

Fix or sell?

  1. Show the bookmarks bar (Ctrl+Shift+B or Cmd+Shift+B).
  2. Drag the orange button onto it.
  3. Open a listing and click it. Selecting the VIN first works too.

3. Call the APIs

    
All four accept cross-origin requests, so a partner front end can call them directly.

    
    
      
  • GET /api/vehicle?vin=: verified title and market values for registered vehicles.
    • 
      
  • POST /api/grade-photos { vin, photos }: 25 part grades, damage flags, missing angles.
    • 
      
  • POST /api/decode-codes { vin, codes, title_status }: fault codes with cost ranges.
    • 
      
  • POST /api/decide { title_status, grades, flags, codes, values }: repair estimate, both net ranges, P(fix wins), verdict.
    • 
    

    
curl -X POST https://underscope-eight.vercel.app/api/decide \
  -H "content-type: application/json" \
  -d '{"title_status":"clean",
       "grades":[{"part":"hood","grade":"replace"},{"part":"front_bumper","grade":"replace"}],
       "flags":{"frame_suspected":false},
       "values":{"clean_wholesale":24500,"salvage_comps":[9800,10400,11200,11900,12600]}}'

  


  

    
What a pilot would swap in
