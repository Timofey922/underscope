      Calling the API

      • GET /api/vehicle?vin= returns the verified title and values for registered vehicles.
      • POST /api/grade-photos with { vin, photos } grades 25 parts.
      • POST /api/decode-codes with { vin, codes, title_status } decodes fault codes.
      • POST /api/decide with { title_status, grades, flags, codes, values } returns both net ranges and the recommendation.
