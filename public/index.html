Underscope API

Fault code decoder for the UB Hacking demo. Enter a VIN and OBD-II codes, or pick a demo scan.

Use it from code 
POST /api/decode-codes
Content-Type: application/json

{ "vin": "1FTYR2CM1KKA12345", "codes": ["C0035", "P0442", "P1450"] }

Returns vehicle, codes[], summary, triage and reason. CORS is open, so the Lovable app can call it directly.
